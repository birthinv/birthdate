# Приглашение на День Рождения

Короткое digital-приглашение в тёмно-белом editorial-стиле, близком к
классическому чёрно-белому: экран открытия, hero с крупной типографикой,
блок с деталями события и обратный отсчёт. Чистый HTML + CSS + Vanilla JS,
без сборки, без npm, без бэкенда. Открывается прямо из файла `index.html`
и работает на GitHub Pages «как есть».

## Структура проекта

```
index.html      — разметка страницы
style.css       — все стили
script.js       — все данные и вся интерактивность
assets/         — музыка и картинка для превью в мессенджерах
README.md       — этот файл
```

## Как менять данные (всё в одном месте)

Открой **`script.js`** — в самом верху файла есть блок:

```js
// ==========================================
// НАСТРОЙКИ ПРИГЛАШЕНИЯ — РЕДАКТИРОВАТЬ ЗДЕСЬ
// ==========================================
const invitation = {
  name: "ЮРА",
  age: "21",
  date: "28 СЕНТЯБРЯ",
  dateShort: "28.09.2026",
  time: "19:00",
  location: "НАЗВАНИЕ МЕСТА",
  address: "Москва, ул. Примерная, 10",
  dressCode: "Чёрно-белый",
  highlights: ["УЖИН", "ТОСТЫ", "ТАНЦЫ", "СЮРПРИЗЫ"],
  eventDateISO: "2026-11-14T19:00:00",
  invitationText: "...",
  music: "assets/music.mp3",
};
```

Все тексты на странице (hero, блок «Приглашаем вас», countdown) подставляются
из этого объекта автоматически через `script.js`. Больше никакие другие файлы
редактировать не нужно.

1. **Имя** — поле `name`.
2. **Дата** (в тексте) — поле `date`. Короткая дата для мелких элементов
   дизайна (badge в интро и hero) — поле `dateShort`.
3. **Время** — поле `time`.
4. **Место проведения** — поле `location`.
5. **Адрес** — поле `address`. Он же используется для кнопки
   «ОТКРЫТЬ НА КАРТЕ» — ссылка на Google Maps строится из этого поля
   автоматически, вручную ссылку менять не нужно.
6. **Дресс-код** (строка в блоке деталей) — поле `dressCode`.
7. **Теги-подсказки о вечере** (маленькие плашки вроде «УЖИН», «ТАНЦЫ») —
   массив `highlights`. Можно добавить, убрать или переименовать любой
   пункт, можно оставить массив пустым `[]`, если они не нужны.
8. **Дата и время для обратного отсчёта (countdown)** — поле `eventDateISO`.
   Формат строго такой: `"ГГГГ-ММ-ДДTЧЧ:ММ:00"`, например `"2026-11-14T19:00:00"`.
   Именно от этого значения считается таймер, а не от `date`/`time` — не забудь
   поменять и его.
9. **Музыка** — положи mp3-файл в `assets/` и назови его `music.mp3`
   (или укажи своё имя в поле `music`). Музыка пытается включиться
   **автоматически** ровно в момент нажатия кнопки «ОТКРЫТЬ» — это разрешено
   браузерами, так как это прямая реакция на клик пользователя. Гость в любой
   момент может выключить и снова включить её кнопкой ♫ в углу экрана.
   Если браузер всё же заблокирует автозапуск (бывает на некоторых
   мобильных браузерах) — ничего не сломается, просто нужно будет нажать
   на кнопку вручную. Если файла нет вообще — кнопка музыки автоматически
   скрывается, сайт продолжает работать как обычно.
10. **Картинка для превью в мессенджерах** (когда отправляешь ссылку в чат) —
    файл `assets/preview.jpg`. Сейчас там лежит сгенерированная
    карточка в стиле сайта — можешь оставить её или заменить на свою
    (рекомендуемый размер 1200×630).

## Как открыть локально

Просто дважды кликни на `index.html` — он откроется в браузере и будет
полностью работать (включая countdown и кнопку карты).

Если хочешь открыть через локальный сервер (не обязательно, но иногда
удобнее для проверки путей к файлам):

```bash
# из папки проекта
python3 -m http.server 8000
# затем открой http://localhost:8000
```

## Как разместить на GitHub Pages

1. Создай новый репозиторий на GitHub (например `birthday-invitation`).
2. Загрузи туда все файлы проекта **как есть**, сохраняя структуру:
   `index.html`, `style.css`, `script.js`, папку `assets/` со всем содержимым.
3. В репозитории открой **Settings → Pages**.
4. В разделе **Build and deployment → Source** выбери **Deploy from a branch**.
5. Выбери branch `main` (или `master`) и папку `/ (root)`, сохрани.
6. Через 1–2 минуты сайт будет доступен по адресу вида:
   `https://<твой-username>.github.io/<имя-репозитория>/`
7. Отправь эту ссылку тем, кого хочешь пригласить.

Все пути к файлам в проекте относительные (`assets/music.mp3`, а не
`/assets/music.mp3`), поэтому сайт корректно работает и в подпапке
GitHub Pages, и при открытии напрямую с компьютера.

## Технологии

Только HTML5, CSS3 и Vanilla JavaScript (ES6+). Шрифты — Google Fonts
(Playfair Display + Jost) с фолбэком на системные шрифты, если интернета
нет. Никаких фреймворков, сборщиков, npm-пакетов, баз данных или backend.
